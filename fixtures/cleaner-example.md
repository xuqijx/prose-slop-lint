# Example Harbor Notes

Example Harbor Notes is a fictional notebook that stays on one computer. It keeps Markdown files in a folder. This example has no account and no remote service.

## What you can do

- Create a note.
- Search notes by the words you type.
- Keep older copies of a note in the same folder.

## How it works

The program reads `.md` files and writes an index beside them. When you edit a note, it updates that index. If a file is missing, the program skips it and prints a warning.

## Limits

This example does not copy notes between computers. You can copy the folder yourself. Search matches words, not meaning.
